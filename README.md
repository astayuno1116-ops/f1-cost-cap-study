# Formula 1 Cost Cap and Qualifying Performance

## Project overview
This repository contains the data and analysis code for the research paper, “Did the Formula 1 Cost Cap Narrow the Performance Gap Between Teams? Evidence from Qualifying Pace and Pre-Cap Budgets”.

## Repository contents
- `data/`: Data used in the analysis.
- `scripts/`: Code used to process the data and estimate the statistical models.
- `documentation/data_dictionary.md`: Definitions of variables, units, sources, and transformations.
- `data/budget_tracker.csv`: Team-budget estimates and their sources.
- `results/`: Tables and figures generated by the analysis.

## Data sources
The study uses publicly available data. The original source for each dataset or estimate is documented in the relevant file or source notes. Budget figures should be interpreted according to the limitations and assumptions described in the paper.

## Reproducing the analysis
1. Install the Python packages listed in `requirements.txt`.
2. Download or clone this repository.
3. Run the analysis script from the project directory.
4. Consult the documentation for variable definitions and source details.

## Data and code availability
The publicly available files in this repository are provided to support transparency and reproducibility of the study.
